# OTT Streaming Content Trend Analysis

## Project Overview
This project analyzes OTT streaming content from Netflix, Amazon Prime Video and Hotstar to identify trends in genre popularity, content ratings, release years, movie duration and country-wise content distribution.

## Objective
- Perform Exploratory Data Analysis (EDA).
- Analyze genre popularity across platforms.
- Compare movies and TV shows.
- Identify release-year trends.
- Analyze country-wise content distribution.
- Present insights using charts and visualizations.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SQL
- Microsoft Excel
- Google Colab

## Dataset
The dataset contains 1,200 sample records with the following columns:
- Show ID
- Platform
- Title
- Type
- Genre
- Country
- Date Added
- Release Year
- Rating
- Duration
- Seasons

Note: This is a synthetic practice dataset created for educational purposes. It does not represent official OTT platform data.

## Project Workflow
1. Dataset collection and loading.
2. Data cleaning and preprocessing.
3. Exploratory Data Analysis.
4. Platform-wise content comparison.
5. Genre and country analysis.
6. Data visualization.
7. SQL queries and aggregations.
8. Business insights and recommendations.

## Visualizations
The project includes:
1. Catalogue size by platform.
2. Most popular genres.
3. Genre distribution across platforms.
4. Movies vs TV shows.
5. Content release-year trends.
6. Movie duration comparison.
7. Top 10 countries by content count.

This project demonstrates how Python, SQL and Excel can be used to analyze OTT streaming catalogues, discover content trends and generate meaningful business insights.
